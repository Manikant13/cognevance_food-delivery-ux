# Food Delivery Mobile App UX Design

## Project Objective
Design a complete mobile app experience for a food delivery platform, based on user research and usability testing.

## Tools Used
- Figma (wireframes, UI screens, prototype)
- Google Forms (user survey)
- FigJam / Miro (journey map)

## UX Workflow
1. Conducted user research and identified pain points
2. Created user personas and journey maps
3. Designed wireframes and interactive prototype
4. Built mobile UI screens using modern UX principles
5. Designed onboarding, cart, and payment flows
6. Performed usability testing and collected feedback
7. Documented UX process and design decisions
